# Sistema de Fila de Pacientes

## Descrição
Projeto desenvolvido em linguagem C para gerenciamento de fila de pacientes utilizando estrutura de dados baseada em array.

## Funcionalidades
- Inserção de pacientes
- Atendimento
- Exibição da fila
- Verificação de capacidade

## Tecnologias
- Linguagem C

## Objetivo
Aplicar conceitos de estruturas de dados e manipulação de memória.
